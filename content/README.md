# Content-Ordner

Hier liegen die **Inhalte der Kurs-Seite** — getrennt von der Präsentation (HTML/CSS/JS in der Site):

- `kurse/` — je Phase ein Dokument mit Lehrplan-Texten (Schritt-für-Schritt-Anleitungen, Erklärungen).
- Ressourcen-Listen (Links zu Tutorials, Übungsplattformen, Videos) je Phase.

Die Texte basieren auf dem Odyseus-Recherche-Report „Web-dev-Kurse für Einsteiger" (Phasen-Progression HTML → CSS → Vanilla JS → Frameworks; hybrides Lernmodell).

**Konvention:** Inhalte zuerst hier pflegen, dann in die Seite einbauen — so bleiben Quellen der Wahrheit und Darstellung getrennt.
